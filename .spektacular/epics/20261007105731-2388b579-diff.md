# Epic: 20261007105731-2388b579-diff

## Overview

Today, someone using xcl can't see what an apply will do until it runs. Diff compares the current configuration against what was last applied. It checks each existing resource against the real system through its provider, and reports which resources would be created, changed, replaced or deleted, and exactly which values would change in each, without changing anything. The result can be inspected by code, or shown to people as a readable, optionally colour-coded summary in the familiar style of a git diff, so they can review a change with confidence before applying it.

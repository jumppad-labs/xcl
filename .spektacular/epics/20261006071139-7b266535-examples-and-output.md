# Epic: 20261006071139-7b266535-examples-and-output

## Overview

Change how xcl's behaviour is tested and how it is shown to people using it. The examples become real-world applications that show how someone would use xcl and test their own configuration code, while xcl's own behaviour is covered by a dedicated end-to-end test suite rather than by the examples. The encoder gains syntax highlighting, so any application can show coloured configuration text, and the prettylog example can drop its own highlighter.

# Epic: 20261009092551-82db0140-plugin-template

## Overview

Plugin authors start a new xcl plugin by copying the examples by hand, so there is no agreed shape for a plugin, no working starting point, and no standard way to publish or install one. This epic defines a standard plugin layout, rebuilds the plugin example to it, adds a way to install plugins straight from GitHub releases, and publishes a template that builds, tests, signs and releases a plugin in that layout, so authors start from a working plugin and users install it with one line of configuration.

## Specs

| # | Spec | Scope |
|---|---|---|
| 1 | 20261009102138-48e95432-docker-example-standard-layout | Rebuild the Docker plugin example to the standard plugin layout, with no change in behaviour |
| 2 | 20261009102148-7d0b205b-github-releases-registry | Install plugins from GitHub releases: pinned versions, checksums, optional GPG trust, private repositories and a cache |
| 3 | 20261009092551-82db0140-plugin-template | A GitHub template repository for xcl plugins in the standard layout, with tests, CI and signed multi-platform releases; depends on 2 |

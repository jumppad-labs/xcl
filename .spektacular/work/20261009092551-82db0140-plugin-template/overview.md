Plugin authors start a new xcl plugin by copying the examples by hand, so there is no agreed shape for a plugin and no working starting point. This feature defines a standard way to lay out an xcl plugin and publishes it as a ready-to-use template: a plugin with one resource that builds, tests and applies straight away, and that runs both inside an application and as a separate program. The plugin example is rebuilt to the same standard, so authors learn one shape and start from a working plugin rather than from scratch.
